# AeroPower-RAG 需求规格说明书 v1.0

> 项目经理制定 | 2026-03-26 | 状态：初稿

---

## 1. 系统概述

### 1.1 项目背景
AeroPower-RAG 是航空发动机适航法规智能问答系统原型，面向航空发动机审定工程师提供 CCAR-33-R2（中国）、FAR-33（美国）、CS-E（欧洲）三大适航体系的法规检索与问答能力。

### 1.2 核心能力
- **法规问答**：用户提问 → 系统返回带出处的答案
- **图谱探索**：法规知识点关系可视化
- **多体系覆盖**：CAAC / FAA / EASA 三局联动

### 1.3 技术架构
```
用户提问
  │
  ▼
┌─────────────────────┐
│  Query Expansion     │  ← 同义词扩展（中↔英）、意图检测
└─────────────────────┘
  │
  ▼
┌─────────────────────┐
│  Hybrid Retrieval    │  ← 向量检索(ChromaDB) + BM25(bigram) + RRF融合
└─────────────────────┘
  │
  ▼
┌─────────────────────┐
│  Multi-Agent Flow    │  ← Planner → Tool → Checker → Answer
└─────────────────────┘
  │
  ▼
┌─────────────────────┐
│  Guardrail验证       │  ← 幻觉检测 + 事实核查
└─────────────────────┘
  │
  ▼
答案 + 引用 + 图谱洞察 + 质量评分
```

## 2. 功能模块规格

### 模块 2.1 —— 查询扩展（Query Expansion）

#### 2.1.1 同义词扩展

| 条目 | 规格 |
|------|------|
| **功能** | 将用户查询中的中文术语扩展为英文同义词（反之亦然） |
| **词典规模** | ≥ 200 条航空发动机术语（中 ↔ 英双向） |
| **覆盖范围** | 发动机、压气机、涡轮、喘振、适航、材料、工艺、强度、噪声等 |
| **扩展深度** | 支持同义词链式扩展（A→B→C） |
| **触发条件** | 所有进入混合检索前的查询 |

**验收标准：**
- [ ] 单元测试：`expand_synonyms("喘振裕度")` 返回包含 "surge margin"、"stall margin"
- [ ] 单元测试：`expand_synonyms("engine")` 返回包含 "发动机"
- [ ] 集成测试：搜索 "compressor surge" 能召回包含 "压气机喘振" 的文档
- [ ] 性能：单次扩展耗时 < 5ms

#### 2.1.2 意图检测（Intent Detection）

| 条目 | 规格 |
|------|------|
| **功能** | 将用户查询分类为 6 种意图之一 |
| **类别** | regulatory（法规要求）、method（方法步骤）、comparison（对比）、definition（定义）、numerical（数值）、cross_reference（交叉引用） |
| **输出** | `Dict[str, float]`，各意图置信度（0.0–1.0），和为 1.0 |
| **默认** | 无法判断时返回 `{"regulatory": 1.0}` |

**验收标准：**
- [ ] "CCAR-33对压气机喘振裕度的要求是什么？" → `regulatory` 置信度最高
- [ ] "如何测量压气机效率？" → `method` 置信度最高
- [ ] "FAR-33和CS-E的区别是什么？" → `comparison` 置信度最高
- [ ] "什么是喘振裕度？" → `definition` 置信度最高
- [ ] "喘振裕度的最小限值是多少？" → `numerical` 置信度最高

### 模块 2.2 —— 混合检索（Hybrid Retrieval）

#### 2.2.1 向量检索

| 条目 | 规格 |
|------|------|
| **引擎** | ChromaDB（本地） |
| **嵌入模型** | Ollama `nomic-embed-text`（768维）或 fallback hash |
| **候选集** | top_k × 4（至少 20 条） |
| **缓存** | 相同查询缓存 100 条结果，TTL 10分钟 |

**验收标准：**
- [ ] 单元测试：相同查询两次调用，第二次返回缓存结果（日志有 "[Cache HIT]"）
- [ ] 集成测试：`search("压气机喘振")` 返回非空结果且包含 metadata
- [ ] 性能：单次检索（无缓存）< 500ms（P95）

#### 2.2.2 BM25 关键词检索

| 条目 | 规格 |
|------|------|
| **分词方式** | 中文 bigram（字 + 二元组合）、英文按单词分词 |
| **公式** | 标准 BM25（k1=1.5, b=0.75） |
| **索引构建** | 懒加载，首次检索时自动构建 |
| **同义词扩展** | 主查询 + 所有同义词项的 BM25 合并（权重 0.3） |

**验收标准：**
- [ ] 单元测试：`tokenize_for_bm25("压气机喘振")` 返回 `["压","气","机","喘","振","压气","气机","机喘","喘振"]`
- [ ] 单元测试：`tokenize_for_bm25("engine test")` 返回 `["engine","test"]`
- [ ] 集成测试：搜索 "engine surge" 能召回包含 "发动机喘振" 的文档
- [ ] 日志：`[BM25] Indexed N documents` 出现于首次检索时
- [ ] 日志：`[BM25] Retrieved N results (expanded with N synonyms)` 显示同义词扩展数量

#### 2.2.3 Reciprocal Rank Fusion (RRF)

| 条目 | 规格 |
|------|------|
| **融合公式** | RRF_score(d) = Σ 1/(k+rank_i(d))，k=60 |
| **输入** | 向量检索结果 + BM25 检索结果 |
| **输出** | 按融合分数排序的 doc_id 列表 |

**验收标准：**
- [ ] 单元测试：给定 `vector=[("a",1),("b",2)]` 和 `bm25=[("b",1),("c",2)]`，融合结果 "b" 排第一（同时出现在两个结果中）
- [ ] 集成测试：融合后结果同时包含向量和 BM25 贡献的文档

#### 2.2.4 关键词重排（Rerank）

| 条目 | 规格 |
|------|------|
| **评分维度** | 关键词匹配、同义词匹配、短语匹配、条款号匹配、权威来源加权、意图匹配、结构位置加权 |
| **权威优先级** | CCAR > FAA > EASA |
| **短语匹配权重** | 章节匹配 +15，标题匹配 +12，正文匹配 +6 |

**验收标准：**
- [ ] "33.65" 作为条款号查询时，包含 "33.65" 的文档排名提前
- [ ] 同等条件下，CCAR-33 来源的文档排名优先于 FAA 文档

### 模块 2.3 —— Multi-Agent 流程

#### 2.3.1 Planner Agent（意图分析）

| 条目 | 规格 |
|------|------|
| **职责** | 分析查询意图，决定是否需要工具调用 |
| **输出格式** | JSON： `{thought, plan, action_list}` |
| **决策边界** | 有工具可调用时 `answer_type=tool`；无需工具时 `answer_type=chat` |

**验收标准：**
- [ ] 单元测试：给定法规查询，输出包含检索工具调用
- [ ] 集成测试：查询 "什么是发动机"（纯定义），不调用检索工具

#### 2.3.2 Tool Agent（检索执行）

| 条目 | 规格 |
|------|------|
| **职责** | 执行混合检索，返回原始检索结果 |
| **输入** | Planner 输出的 action_list |
| **输出** | 检索到的文档片段列表 |

**验收标准：**
- [ ] 集成测试：检索 "压气机喘振"，返回 ≥ 1 条相关文档
- [ ] 日志：`[BM25]` 和 `[Hybrid]` 日志正常输出

#### 2.3.3 Checker Agent（质量验证）

| 条目 | 规格 |
|------|------|
| **职责** | 验证检索结果与查询的相关性（不生成答案） |
| **输出格式** | JSON： `{relevance_scores: [0.85, 0.6, ...], reasoning: "..."}` |
| **相关性分数** | 每条结果 0.0–1.0，共 5 级 |
| **重试机制** | 最多 3 次重试 |

**验收标准：**
- [ ] 高相关结果（包含查询关键词）评分 ≥ 0.7
- [ ] 不相关结果评分 ≤ 0.2
- [ ] JSON 解析失败时优雅降级（不影响最终答案）

#### 2.3.4 Answer Agent（答案生成）

| 条目 | 规格 |
|------|------|
| **职责** | 基于 Checker 验证后的结果生成最终答案 |
| **输出格式** | 结构化答案：直接回答 + 条款依据 + 适用说明 + 质量评估 |
| **引用标注** | 每个答案必须有 ≥ 1 条引用 |

**验收标准：**
- [ ] 答案中包含 "【直接回答】"、"【条款依据】" 等结构化段落
- [ ] 每条引用包含来源文件、章节、原文片段
- [ ] 无法找到相关文档时返回 "抱歉，暂未找到相关内容"（不 hallucinate）

### 模块 2.4 —— 检索质量保障

#### 2.4.1 Guardrail（事实核查）

| 条目 | 规格 |
|------|------|
| **功能** | 验证答案内容与检索上下文的一致性 |
| **状态** | PASS / PARTIAL / FAIL / UNVERIFIED |
| **幻觉检测** | 标记答案中无证据支撑的声明 |
| **安全回答** | 核查失败时返回保守的安全回答 |

**验收标准：**
- [ ] 答案与证据一致时：`status=PASS`，`has_hallucination=false`
- [ ] 答案部分超出证据时：`status=PARTIAL`
- [ ] 答案严重偏离证据时：`status=FAIL`，`has_hallucination=true`
- [ ] LLM 不可用时：`status=UNVERIFIED`

#### 2.4.2 置信度评分（Quality Score）

| 条目 | 规格 |
|------|------|
| **评分维度** | 来源覆盖、引用密度、术语精确度、交叉验证、数值特异性、权威权重、一致性（7 维度） |
| **输出范围** | 0.0–1.0 |
| **显示字段** | `confidence` 字段随 API 响应返回 |

**验收标准：**
- [ ] 高质量答案（多引用、高相关）：confidence ≥ 0.7
- [ ] 低质量答案（少引用、低相关）：confidence < 0.4

### 模块 2.5 —— 知识图谱

#### 2.5.1 图谱数据

| 条目 | 规格 |
|------|------|
| **存储** | Neo4j 图数据库 |
| **节点类型** | Regulation, Chapter, Section, Clause, Component, Parameter |
| **边类型** | CONSTRAINS, REQUIRES, APPLIES_TO, RELATED_TO, DEFINES |
| **节点属** | CAAC（红） / FAA（蓝） / EASA（绿）/ UNKNOWN（灰） |

**验收标准：**
- [ ] API `/graph/nodes` 返回所有节点列表
- [ ] API `/graph/network` 返回全量密集图数据
- [ ] API `/graph/subgraph?query=压气机` 返回以查询为中心的局部子图

#### 2.5.2 图谱展示（UI）

| 条目 | 规格 |
|------|------|
| **布局** | D3.js Force-Directed Graph |
| **交互** | 缩放（+ / - / 重置）、拖拽节点、点击节点查看详情 |
| **颜色编码** | 节点颜色按机构区分 |
| **图例** | 显示 CAAC/FAA/EASA 颜色映射 |

**验收标准：**
- [ ] 首次进入图谱页面，自动加载全量网络图（不显示空画布）
- [ ] 切换"只看子图"后，根据查询加载局部子图
- [ ] 从全图切换到子图再切回全图，状态正确重置
- [ ] 节点颜色与机构匹配（不是全灰）

#### 2.5.3 inferAgency 推理

| 条目 | 规格 |
|------|------|
| **规则** | `group` 字段 > `document` 前缀（CCAR-/FAR-/CS-） > 默认灰色 |
| **优先级** | `centerNode` subgraph > `fullGraphMode` |

**验收标准：**
- [ ] 节点 document 以 "CCAR-" 开头 → 红色
- [ ] 节点 document 以 "FAR-" 开头 → 蓝色
- [ ] 节点 document 以 "CS-" 开头 → 绿色
- [ ] 无 document 字段且无 group → 灰色

### 模块 2.6 —— 前端 UI

#### 2.6.1 证据面板导航

| 条目 | 规格 |
|------|------|
| **功能** | 用户点击证据卡片 → 查看全文 → 可返回证据列表 |
| **列表保留** | 返回后恢复上一次证据列表，不重新请求 API |

**验收标准：**

- [ ] 在详情页点击返回按钮，恢复证据列表（不闪烁）
- [ ] 进行新搜索后，证据列表更新，旧列表被替换

#### 2.6.2 官方来源链接

| 条目 | 规格 |
|------|------|
| **来源映射** | 证据引用 → catalog 中的 `official_url` |
| **备用规则** | 无 official_url 时使用 `document_url` |
| **前缀匹配** | `caac-ccar-33-r2` 可匹配 `CCAR-33-R2`（脱前缀后匹配） |
| **显示位置** | 证据卡片提供 "查看官方来源" 链接（图标按钮） |

**验收标准：**
- [ ] CCAR-33-R2 相关证据的 officialUrl 不为空
- [ ] 点击官方来源链接可打开 CAAC/FAA/EASA 官网对应页面
- [ ] 日志无 "officialUrl is empty" 警告

#### 2.6.3 筛选功能

| 条目 | 规格 |
|------|------|
| **辖区筛选** | CAAC / FAA / EASA 多选，支持同时激活多个 |
| **层级筛选** | L0核心法规 / L1认证指南 / L2环境与生命周期 |

**验收标准：**
- [ ] 取消勾选 "CAAC" 后，证据列表中无 CCAR 来源
- [ ] 取消勾选 "FAA" 后，证据列表中无 FAR 来源
- [ ] 筛选变化后立即生效，无需点击确认按钮

#### 2.6.4 模式描述

| 条目 | 规格 |
|------|------|
| **法规问答模式** | 显示 "探索航空发动机适航法规的智能助手" |
| **图谱探索模式** | 显示 "发现法规条款之间的深层关联" |
| **切换反馈** | 模式切换时，描述文本和图标同步更新 |

**验收标准：**
- [ ] 切换到图谱探索模式，描述变为对应文案
- [ ] 切换回法规问答模式，描述恢复原样

#### 2.6.5 条款展示

| 条目 | 规格 |
|------|------|
| **格式** | 每条款单独展示，标注相关性（高/中/低） |
| **高相关** | 显示绿色标签 "✔️高度相关" |
| **中相关** | 显示黄色标签 "⚠️中度相关" |
| **低相关** | 显示灰色标签 "○低相关" |

**验收标准：**
- [ ] 每条证据单独一行（非合并段落）
- [ ] 相关性标签与 LLM 评估分数对应显示

### 模块 2.7 —— API 端点

| 端点 | 方法 | 规格 |
|------|------|------|

## 3. 测试实施规范

### 3.1 测试分层

```
┌─────────────────────────────────────────┐
│  E2E 测试（用户故事测试）                 │  ← pytest tests/e2e/
│  例：用户查询 → 收到带引用的答案            │
├─────────────────────────────────────────┤
│  集成测试（模块协作测试）                  │  ← pytest tests/integration/
│  例：检索 → 重排 → Agent 流程              │
├─────────────────────────────────────────┤
│  单元测试（纯函数/类测试）                 │  ← pytest tests/unit/
│  例：BM25.tokenize_for_bm25()            │
└─────────────────────────────────────────┘
```

## 5. 发布门槛（Release Criteria）

**以下所有条目必须通过方可发布：**
